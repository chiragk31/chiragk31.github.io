### 🏆 VaaniPath — Smart India Hackathon 2025 Winner

**VaaniPath** is an AI-powered multilingual platform built to make digital learning and educational content more accessible across Indian languages. The project focuses on breaking language barriers by enabling the processing, translation, and localization of educational content into regional languages.

I worked as part of the team that developed and presented VaaniPath at the **Smart India Hackathon 2025 Grand Finale**, where our team **won the hackathon**.

#### 🔑 Key Features

* 🎙️ **Speech & language processing** for educational content
* 🌐 **Multilingual translation** with a focus on Indian languages
* 🎧 **Audio localization and dubbing** for learning content
* 📄 **Document translation and processing**
* 🔊 **Text-to-speech based localized content generation**
* 🛡️ Content processing and filtering for safer educational experiences
* ⚙️ Separate **Frontend, Backend, and Localizer** components for modular development

#### 🛠️ Technologies

**Python · FastAPI · FFmpeg · Indic Language Processing · Text-to-Speech · REST APIs · React · AI/ML**

This experience taught me how to take a problem from **ideation → architecture → rapid development → integration → testing → final presentation** under real hackathon constraints.

🏆 **Achievement: Smart India Hackathon 2025 — Winner, Grand Finale**
